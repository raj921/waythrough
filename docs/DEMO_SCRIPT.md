# WayThrough demo script

Keep the recording under three minutes. Use the live Convex URL and a clean browser session.

1. Start a private session. Say: “WayThrough begins with a route, not a confident summary.”
2. Open the fictional Riverside Gallery example. Point to the five route steps and the amber entrance arrangement.
3. Open Evidence and show the exact source wording, capture time, and fictional-fixture label.
4. Confirm staffing. The entrance becomes supported and the overall route becomes supported.
5. Create a read-only share link in a second browser tab. Explain that it contains the route but not requirements or email bodies.
6. Withdraw staffing. The live route reopens the entrance arrangement. Revoke the link and show the read-only view disappear.
7. End on Connections. Say: “A configured provider is not presented as proof of a provider call. With keys configured, the same flow retrieves a real venue page, extracts grounded claims, sends one reviewed request, and interprets a signed reply.”

If provider keys are configured before recording, use a public venue accessibility page and a controlled recipient address. Do not record API keys, private requirements, or a real person’s mailbox without permission.
